# iw-cwc-interaction
Analysis of internal wave - cold water coral interaction in the North Atlantic Ocean conducted for the paper on 'Buoyancy effects and internal wave dynamics in cold-water coral provinces of the North Atlantic', _Progress in Oceanography_
Some of the functions and scripts are yet to be migrated to the repository, as I was rather inconsistent in committing changes via git. If I find time, I hope to add a master script for the individual case study areas, pulling together component scripts. As it stands, the repository contains some useful (occasionally even well annotated) code for the various analyses performed.  If you find this useful (or spot any mistakes), please be in touch. Scripts are provided under the GNU GPL-v3 license included in the repository. Running any code will invariably require supplying it with your data (due to ownership and/or size restrictions, input data hasn't been included, though derived data is provided where possible), fixing directory paths and ensuring all assumptions are met.
